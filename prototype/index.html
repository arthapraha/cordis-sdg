Methodological Findings & Constraints

  • Vocabulary Divergence & The Recall Ceiling (0.442): Keyword and text-matching pipelines cannot reach 53 of 95 gold-standard target associations because CORDIS project descriptions and UN SDG target texts use non-overlapping terminologies. This ceiling is an inherent property of lexical overlap, not a pipeline bug.
  • Unassigned Corpus Rate (30.6%): 7,175 of 23,451 projects receive no SDG assignment (assignment_level: none). Calibrated thresholding intentionally rejects low-confidence matches to preserve high precision (0.447) rather than forcing arbitrary labels.
  • Single-Reference Annotation Limit: Hermes Cordis's set is the sole reference for all 100. Section 4.8 provides for Attila's call on the 20 he hand-labelled and Hermes's labels as the reference for the other 80; THE 20 WERE NEVER MADE, so there was nothing to adjudicate, no call was taken, and the limitation covers the whole hundred. Section 4.3 provides for 20 of the 100 to be hand-labelled by Attila as the human anchor, and section 4.7 reports agreement against them separately. They were not made. The evaluation reference rests entirely on one automated labeller working blind, and nothing in this report is anchored to a human judgement.
  • Parked Explanation Pass (§3.7): To ensure 100% deterministic reproducibility without external API key dependencies, model-generated explanations were parked under registration §3.7 during the frozen run.

2. Binding Render Rules (Room seq 266 & 267)

  • Unescaped Hyphen Titles: Two project titles begin with a leading hyphen (101073045 and 101275778). They are raw CORDIS source bytes. This prototype preserves them verbatim without escaping.
  • Parked Explanation Markers: The explanation and prompt_sha256 columns carry explicit §3.7 parked markers. They are rendered as distinct status notification badges, never as model-generated explanatory text.
  • Sources Present vs. Absent: The prototype prominently surfaces sources_present and sources_absent side-by-side so readers can distinguish "field matched nothing" from "field was absent in CORDIS record".
  • No Chart Redrawing: The six figures drawn by the notebook are embedded directly without redrawing or reinterpretation.

3. Zero-Dependency Static Deployment

All data is served as static pre-indexed JSON (prototype/data/). The application requires no external backend server, no database, no API keys, and zero CDN dependencies.
